# Instagram @agprivate.agent

Pliki publikowane automatycznie na Instagramie przez Windsor.ai.
Instagram pobiera grafiki z publicznych linków raw.githubusercontent.com, dlatego są w tym publicznym repozytorium.

- `zdjecia/` – zdjęcia referencyjne Andrzeja do okładek grafik
- `posty/RRRR-MM-DD/` – grafiki JPEG 1080x1350 na dany tydzień (nazwa folderu = poniedziałek)
- `posty/RRRR-MM-DD/plan.json` – plan publikacji tygodnia (dzień, godzina, typ, opis, pliki, status)

Ten folder nie jest częścią strony agprivate.pl.
